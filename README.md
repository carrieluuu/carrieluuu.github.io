# Carrie API demo site

A tiny static website used to demonstrate crawling, categorization, and change monitoring in the automated `llms.txt` generator.

The initial version contains an overview, documentation, and API resources. A first-request guide is intentionally reserved for the monitoring demo, where publishing the new page should produce one added resource and a new generated-file version.

Serve the repository root with any static file server, or enable GitHub Pages for the `main` branch.
