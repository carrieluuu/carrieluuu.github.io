Carrie API guide

Make your first request in three small steps.

Start with a friendly endpoint, send a standard GET request, and inspect the JSON response. No authentication or request body is needed for this fictional API demo.

1. Choose an endpoint

Use the random-fact endpoint for a quick first request. It returns one public, lighthearted detail about Carrie. The endpoint is read-only, so experimenting with it never changes data. 

GET /api/facts/random

2. Send the request

Run the curl command below in a terminal. A real API client could make the same HTTPS request from JavaScript, Python, or another language. The static demo site illustrates the interface and does not provide a live API response. 

curl https://carrieluuu.github.io/api/facts/random

3. Read the response

A successful response contains a data object with the fact and a metadata object describing the API version. This predictable shape lets a client display the fact while keeping response details separate. 

{
  "data": {
    "fact": "Carrie enjoys building thoughtful developer tools."
  },
  "meta": {
    "version": "v1"
  }
}
