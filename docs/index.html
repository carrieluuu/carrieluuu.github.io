Carrie API docs

Everything you need to make a request.

Carrie API is a fictional, read-only JSON API. It needs no authentication, never modifies data, and now documents a consistent request and error model for every endpoint.

Request fundamentals

Send a GET request to the base URL followed by an endpoint. Include an Accept: application/json header when your client supports it. Successful responses use JSON and a 200 status; invalid resource paths return a structured 404 response. The demo endpoints below illustrate the intended interface, while this static site does not run an API server.

curl --header "Accept: application/json" \
  https://carrieluuu.github.io/api/facts/random

Endpoints

GET /api/about

Returns a short profile with Carrie's background and current focus.

GET /api/interests

Returns grouped interests such as building software, thoughtful design, travel, and trying new food.

GET /api/projects

Returns selected software projects and a short description of each one.

GET /api/facts/random

Returns one randomly selected, public, lighthearted fact about Carrie.

Responses and errors

Successful responses contain a data object and metadata with the API version and request timestamp. Errors use a stable code, human-readable message, and documentation link. This consistent structure makes the API easy to explore from a browser, script, or API client.

{
  "data": {
    "fact": "Carrie is always planning her next build."
  },
  "meta": {
    "version": "v1",
    "generated_at": "2026-10-11T17:00:00Z"
  }
}
