Carrie API docs

Everything you need to make a request.

Carrie API is a fictional, read-only JSON API. It needs no authentication, never modifies data, and uses predictable resource-oriented URLs.

Quickstart

Send a GET request to the base URL followed by an endpoint. Responses use JSON and include a successful HTTP status code. The demo endpoints below illustrate the intended interface; this static site does not run an API server.

curl https://carrieluuu.github.io/api/facts/random

Endpoints

GET /api/about

Returns a short profile with Carrie's background and current focus.

GET /api/interests

Returns grouped interests such as building software, thoughtful design, travel, and trying new food.

GET /api/projects

Returns selected software projects and a short description of each one.

GET /api/facts/random

Returns one randomly selected, public, lighthearted fact about Carrie.

Response format

Successful responses contain a data object and a small metadata object. Errors use a stable code and human-readable message. This consistent structure makes the API easy to explore from a browser, script, or API client.

{
  "data": {
    "fact": "Carrie is always planning her next build."
  },
  "meta": {
    "version": "v1"
  }
}
