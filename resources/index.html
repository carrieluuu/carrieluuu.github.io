Meet Carrie

02

Browse interests

Use JavaScript to retrieve Carrie's interests and render them in an application.

const response = await fetch(
  "https://carrieluuu.github.io/api/interests"
);
const { data } = await response.json();
03

Find a fun fact

Ask for a random fact whenever your project needs a small dose of Carrie context.

import requests

response = requests.get(
    "https://carrieluuu.github.io/api/facts/random"
)
print(response.json()["data"]["fact"])
