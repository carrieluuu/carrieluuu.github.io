API features

Small endpoints, thoughtfully structured.

Carrie API organizes a playful personal profile into predictable JSON resources. Each read-only endpoint is designed to be understandable at a glance and easy to use in a small project.

01

Focused resources

Request a profile, grouped interests, selected projects, or one random fact without downloading unrelated information. 

GET /api/about
GET /api/interests
GET /api/projects
GET /api/facts/random
02

Consistent JSON

Every successful response separates its data from version and request metadata, giving clients one stable shape to handle. 

{
  "data": { "topic": "building" },
  "meta": { "version": "v1" }
}
03

Safe to explore

The fictional API is read-only and requires no credentials. Its static documentation makes the interface clear without exposing private information or accepting writes. 

Accept: application/json
Method: GET
Authentication: none
